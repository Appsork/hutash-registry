# hutash-registry

Public distribution channel for Hutash `.hutash` packages: `index.json`,
`pipelines/*.hutash`, and `apps/*.hutash`. Nothing else lives here.

The `.hutash` package format spec (three-layer structure, `manifest.yaml`,
parameter schema for the `capabilities:` block) is documented at
`hutash-studio/docs/HUTASH_FORMAT.md` in the Hutash Studio repository —
not in this repo.
